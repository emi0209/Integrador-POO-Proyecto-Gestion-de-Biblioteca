# Integrador-POO-Proyecto-Gestion-de-Biblioteca
Sistema de gestión de préstamos de libros para bibliotecas desarrollado en Java con Orientación a Objetos. Administra libros, préstamos y tipos de socios (Estudiantes y Docentes), validaciones de vencimientos y generación de reportes utilizando colecciones genéricas. (Trabajo Práctico Integrador - POO)
